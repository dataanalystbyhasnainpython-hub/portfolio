# Muhammad Hasnain — Professional IT Portfolio

A professional, responsive IT portfolio website for **Muhammad Hasnain** — Software Engineer · Python Developer, built as part of the *Professional IT Portfolio Development & Web Deployment* additional learning activity (Parallel and Distributed Computing, Department of Software Engineering, University of Sindh, Jamshoro).

🔗 **Live website:** https://portfolio-muhammad-hasnain-b8et6cli5a.vercel.app/

## 🚀 How to Run Locally

No build step or dependencies are required — the site is a single self-contained HTML file.

```bash
# Option 1: just open it
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux

# Option 2: serve it (recommended)
python -m http.server 8000
# then visit http://localhost:8000
```

## 📦 What's Inside

Everything is embedded inside `index.html` (CV PDF and demo videos are included as base64 data), so the site works offline and needs no extra hosting configuration:

| Asset | How it is served |
|---|---|
| CV (`CV_Muhammad_Hasnain.pdf`) | Embedded — "View CV" opens it in a new tab; "Download CV" saves it |
| 4 demo videos (eye detection, fourth dimension, hand gesture, hasnain mall) | Embedded as `data:` URLs — play for every visitor |
